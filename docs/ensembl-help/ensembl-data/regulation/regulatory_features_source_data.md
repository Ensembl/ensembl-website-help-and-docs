# Source data for regulatory feature annotation

Ensembl’s regulatory annotations are based primarily on ChIP-seq, DNase-seq, and ATAC-seq data generated by the [ENCODE](https://www.encodeproject.org/) and [FAANG](https://data.faang.org/) consortia, and gene annotation from Ensembl/GENCODE.

We currently provide regulatory annotations for ten species. The metadata of the source data we have used to produce our annotation can be viewed at <https://regulation.ensembl.org/source_data/>.
